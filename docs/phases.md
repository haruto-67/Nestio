- [x] 再読み込み時に直前の画面/ビューを復元（`localStorage`）

## 改修5回目：ユーザーフィードバック対応（2026-08-06）

ユーザーが「採用」「ほしい」等で選定した16件を実装し、それ以外の未選定案は見送りとしてクローズした。

      iOS Safariのズーム対策CSS（`input, textarea, select { font-size: 16px }`）の対象漏れが原因と判明。
      `[contenteditable]`をセレクタに追加
- [x] モバイル幅でのヘッダー崩れ（タイトルが「N」まで潰れる表示バグ）を修正 → 改修4回目で追加した
      カンバン/カレンダー切替ボタンが優先度フィルタ・並び替えと同じ行に収まりきらなくなっていた回帰。
      モバイル幅ではコントロール群を2行目に折り返すレイアウトへ変更
- [x] タスク詳細パネルが開く時の軽いスライドインアニメーションを追加

      巻き込まれて見失いやすかった不具合を修正（非スクロールの外枠にハンドルを配置）
